## 2. Mode de fonctionnement de Packet Tracer

Packet Tracer est un outil de base en informatique pour l'efficacité en technologie, spécifiquement dans le domaine des systèmes, réseaux, télécoms et parfois en architecture des réseaux électriques. Le mode de fonctionnement des architectures est tourné vers des personnes qui sont dans le domaine de la technologie et qui peuvent comprendre comment cela fonctionne afin de faire une conception du même genre, la simulation pour faire une installation des outils pour créer un réseaux. Dans le cas où on peut souhaite faire une exécution des éléments de fichier afin de voir le modèle, ensuite la conception et ensuite la simulation.

Premièrement, vous devez entrer dans le dossier qu'on appelle `packet-tracer-arch`.

après, vous devez choisir une architecture qui vous convient. Une architecture sous une extension de `.pkt`, ce sont les différents éléments du réseaux afin de faire une simulation conviviale pour voir le mode de fonctionnement.

Exemple : vous pouvez choisir un fichier de simulation pour l'architecture qu'on appelle `hockague_stage.pkt`. Cette architecture permet de voir les différents éléments d'un réseaux afin de faire une simulation dans la suite et voir le mode du fonctionnement du réseaux à appliquer.

Dans ce même cadre, est ce que Packet Tracer possède des avantages dans la modélisation des architectures réseaux ?

3. Les avantages de Packet Tracer dans la modélisation et la conception des architectures réseaux

Les avantages de l'utilisation de Packet Tracer pour faire la modélisation des architectures Systèmes et Réseaux sont un peu incalculable, pour cela, nous allons nous concentrer sur la partie exhaustive.



- Avantage 1 : Packet Tracer est un outil de base de CISCO

CISCO est une grosse entreprise au États - Unis qui intervient dans la vente et la commercialisation des outils de réseaux informatiques dans le monde entier, pour cela, nous avons la possibilité de savoir dans un cadre général que c'est l'entreprise CISCO qui a créé un outil qu'on appelle Packet Tracer.



- Avantage 2 : CISCO fait des cours de CCNA pour donner des certifications reconnues mondialement

CISCO qui est une entreprise source de Packet Tracer donne des cours en ligne pour fournir des certifications reconnues mondialements. Cette certification est une grande base pour avoir une reconnaissance dans le monde de la technologie spécifiquement dans le monde des réseaux et télécommunication.



- Avantage 3 : Packet Tracer est un outil qui n'est pas trop compliqué à être maîtrisé

CISCO est de base un outil de simulation, cet outil permet éssentiellement de faire des simulations en passant par l'interface graphique, pour ce cas précis, il y a possibilité de d'ajouter des éléments technologiques et ensuite, créé une liaison entre ces éléments architecturaux et ensuite faire une simulation qui sera à un sens littérallement correct.
