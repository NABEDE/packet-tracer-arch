## 1. Introduction

L'utilisation des outils pour la modélisation des éléments de système et réseaux sont standardiser dans le monde, c'est pour cette raison que les ingénieurs ont créer un outil qu'on appelle `Packet Tracer`, c'est un outil de base d'une entreprise en Grande Technologie qu'on appelle `CISCO`. Pour cela, la modélisation et la conception des architectures de systèmes ou réseaux ou encore dans le domaine de la télécommunication ou autres compatible, peuvent paraître compliqués pour les débutants parfois pour des intermédiaire dans la création des solutions en ingénierie technologique. De ce fait, certaines personnes dans leurs études scientifiques en technologie produisent des architectures pour présenter cela afin de soutenir dans leurs études, dans l'usage de cette application et de produire un rendu équitable dans le domaine de la technologie. Pour cela, je suis pratiquement dans le même genre que ces personnes pour faire des publications des différentes architectures que j'ai publié actuellement sur ce dépôt GitHub.

## 2. Mode de fonctionnement de Packet Tracer

Packet Tracer est un outil de base en informatique pour l'efficaté en technologie, spécifiquement dans le domaine des systèmes, réseaux, télécoms et parfois en architecture des réseaux électriques. Le mode de fonctionnement est prfois tourné vers des personnes qui sont dans le domaine de la technologie et qui peuvent comprendre comment cela fonctionne.
